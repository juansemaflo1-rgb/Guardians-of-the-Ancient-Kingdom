# Guardians of the Ancient Kingdom

Sistema de combate por turnos desarrollado en Python aplicando los principios de la Programación Orientada a Objetos (POO).

---

## 1. Descripción del Proyecto
El sistema simula combates por turnos entre tres clases de guardianes (Guerreros, Magos y Arqueros) en el reino de Eldoria. Permite controlar los turnos, aplicar habilidades especiales, validar los datos de los personajes y determinar automáticamente el ganador o el empate.
